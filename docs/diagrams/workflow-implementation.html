2. Secure Authentication & Onboarding Workflow

Visualizing how an anonymous user is securely authenticated without storing plain-text PII (emails).

sequenceDiagram participant U as User (Next.js) participant A as API (Express) participant R as Redis participant DB as PostgreSQL participant M as Mail Server U->>A: POST /auth/request-otp (email) A->>DB: Check college domains A->>A: Hash email (HMAC + Pepper) A->>DB: Store hashed OTP temporarily A->>M: Send Plaintext OTP M-->>U: Receives Email U->>A: POST /auth/verify-otp (email, code) A->>A: Hash email & Hash code A->>DB: Verify hashes match alt Success A->>DB: Upsert User (Using hashed email) A->>R: Generate Secure Session ID A-->>U: Set HttpOnly Cookie else Failure A-->>U: 401 Unauthorized end

3. Matchmaking & Real-Time Chat

The sequence of events when two users are paired anonymously in the matching queue.

sequenceDiagram participant U1 as Student A participant S as Socket Server participant R as Redis Queue participant U2 as Student B U1->>S: Emit "match:search" (Filter: SAME_YEAR) S->>R: Add Student A to Pool U2->>S: Emit "match:search" (Filter: ANY) S->>R: Add Student B to Pool Note over S,R: Matcher Cron runs every 100ms S->>R: Evaluates Pool (A & B are compatible) S->>S: Create ChatSession in DB S->>R: Remove A & B from Pool S-->>U1: Emit "match:joined" S-->>U2: Emit "match:joined" U1->>S: Emit "session:message" (Hello) S->>S: Encrypt & Moderate Message S-->>U2: Emit "session:receive" (Hello)
